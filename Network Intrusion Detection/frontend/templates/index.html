Network Intrusion Detection System

This agent uses a Random Forest classifier trained on a synthetic NSL-KDD-style dataset to classify network traffic into five categories:

Normal

Legitimate network traffic with no malicious indicators.

DoS

Denial-of-Service attacks designed to overwhelm system resources.

Probe

Surveillance attacks that scan networks to gather information.

R2L

Remote-to-Local attacks exploiting remote access vulnerabilities.

U2R

User-to-Root attacks escalating user privileges to root access.

Architecture

  • Backend: Flask (Python) REST API
  • ML Model: Random Forest — 150 trees, trained on 5 000 synthetic NSL-KDD samples
  • AI Explanations: IBM WatsonX (meta-llama/llama-4-maverick)
  • Frontend: Vanilla HTML/CSS/JS dashboard
